# Sparkfield — What's New in 0.1.7

## Superhero Event — new
20 new droids, event-only (never spawn outside the event, don't count
toward the main Dex):
- **15 usable now, art included** — Mightron, Pixielight, Velocity,
  Orbital Mage, Night Sentinel, Stingray, Frostblaze, Terrabolt,
  Luminova, Crimson Edge, Solaris Guard, Cyberwraith, Skylite, Cosmion,
  Aquawave. Rarity/alignment assigned across the full spread
  (Common → Legendary, Light/Dark/Cosmic).
- **5 flagged, names only for now** — Patriotix, Webstriker,
  Thunderion, Shadowclaw, Iron Ascent. These were visually unmistakable
  as existing copyrighted Marvel characters despite the renaming, so
  no artwork was used for them — the species exist in-game and are
  ready the moment new original designs replace them.
- New **blue** "Start Superhero Event" admin button, 2-hour duration.
- Event Dex reworked into two boxes — a selector box and a content
  box — each with its own background support.

## Everywhere
- The Event Dex button color system is now general-purpose (a proper
  color map per event) instead of a one-off hardcoded case for Summer
  — this is what let the Superhero button be genuinely blue without
  bolting on another special case.

---

*Worth knowing: cropping the 15 usable designs out of the source sheet
took two passes — the first trim left a sliver of name-label text
visible on one image (Aquawave). Caught it, widened the crop margin,
and re-checked all 15 individually rather than assuming the fix
generalized to the rest.*
