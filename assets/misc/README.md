# Misc Artwork

One-off generic images that aren't tied to a specific droid species or
outfit. Same drop-in pattern — exact filename, drop it in, done.

## Exact filenames needed

| Filename | Where it's used |
|---|---|
| `egg.png` | The unassigned-egg icon on the Factory section of Field Ops (replaces the 🥚 emoji) |
| `control-pad.png` | Background image behind the LOCK-ON capture minigame's sweep bar |
| `bg-light.png` | Background on radar spawn cards for Light-alignment droids |
| `bg-dark.png` | Background on radar spawn cards for Dark-alignment droids |
| `bg-cosmic.png` | Background on radar spawn cards for Cosmic-alignment droids (companions) |
| `working.gif` | Small animated icon shown in the corner of an active Farm slot |

All formats accepted: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.svg` —
but note `working.gif` specifically needs to actually be an animated
GIF to show motion (a static PNG will just sit still, which is fine
too if that's what you'd prefer).

If any file is missing, everything falls back gracefully — spawn cards
just show the normal panel color, the egg icon falls back to 🥚, the
pad background is just blank, and the Farm slot simply has no
animation icon. Nothing breaks.
