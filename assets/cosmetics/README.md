# Cosmetic Item Artwork

Same pattern as `assets/droids/` — drop an image here named after the
cosmetic's `id`, and it'll be picked up automatically.

**Supported formats:** `.png` (preferred), `.jpg`, `.jpeg`, `.webp`, `.gif`,
`.svg`. If no image exists for a cosmetic, the shop just shows its name as
text — nothing breaks.

## Current cosmetics

- `beta_crown.png` — Beta Crown

As more cosmetics are added to `COSMETICS_CATALOG` in `src/db.js`, add an
image here named after each new `id` the same way.
