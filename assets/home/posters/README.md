# Event Posters

Drop any image in here, any filename you like — the Home page
automatically lists and displays whatever's in this folder. No code
changes needed to add or remove a poster.

Landscape orientation recommended (confirmed with you). Supported
formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.svg`.

Delete a file from here and it disappears from the Home page
immediately — no other cleanup needed.
