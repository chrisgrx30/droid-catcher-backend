# Home Page Artwork

## Exact filenames needed

- `logo.png` — shown in the Home page header. Transparent background
  recommended. Falls back to a plain text "Sparkfield" title if missing.
- `icon.png` — used as the custom icon when the app is saved to an iOS
  home screen. Falls back to the browser's default icon if missing.

## Posters

Event posters go in the `posters/` subfolder, not here. See
`posters/README.md`.
