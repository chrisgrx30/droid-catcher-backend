# Outfit Artwork

Same drop-in pattern as `assets/droids/` — name the file after the
outfit's id, drop it here, done. Supported formats: `.png` (preferred),
`.jpg`, `.jpeg`, `.webp`, `.gif`, `.svg`.

## Exact filenames needed

- `earthy.png`
- `technology.png`
- `wildlife.png`
- `funky.png`

## Optional

- `basic.png` — the free default outfit every player starts with. Not
  required; if missing, the UI just shows a 👤 placeholder for it.

If any file is missing, that outfit falls back to a 👤 icon — nothing
breaks, it just won't have art yet.
